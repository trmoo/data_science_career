# 데이터 과학 영향력 탐구

고등학교 「데이터 과학」 **[12데과01-04]** 수업용 웹앱입니다.
학생이 **데이터로 달라진 세상**을 평가하고, 그 안에서 **자기 진로를 설계**해 여섯 항목을 서술합니다.
사례는 「기술이 좋아졌다」가 아니라 **어떤 기록을 모아 어떻게 분석해 무엇을 결정했는지**로 씁니다.
작성 내용은 자동 저장되고, **교사 스프레드시트에 학생 한 명 = 한 줄**로 쌓입니다.

> 학생 화면에도 「뱃지 개수로 점수가 갈리지 않는다」고 적어 두었습니다.

## 설치 (교사가 한 번만)

1. 구글 드라이브에서 **스프레드시트를 새로 만든다.**
2. **확장 프로그램 → Apps Script** 를 누른다.
3. 왼쪽 ⚙️ **프로젝트 설정** → 「`appsscript.json` 매니페스트 파일 표시」를 **켠다.**
4. `npm run pack` 으로 만든 `dist/appsscript/` 의 파일 13개를 **이름별로 붙여넣는다.**
   (자세한 순서는 `dist/appsscript/붙여넣는 순서.md`)
5. 저장 후 스프레드시트로 돌아가 **새로 고침** → 위쪽에 메뉴가 생긴다.
6. 메뉴 → **① 시트 준비하기** 를 한 번 실행한다. (권한 승인 창이 뜨면 허용)
7. 편집기에서 **배포 → 새 배포 → 웹 앱** · 실행 대상 **나** · 액세스 권한 **모든 사용자**
   → 나오는 주소를 학생에게 알려 준다.
8. 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 새 버전 → 배포**.
   새 배포를 만들면 **주소가 바뀌니** 반드시 「수정」으로 할 것.

## 학생에게 알려 줄 것 (3줄)

1. 주소를 열고 **학번**을 넣습니다. 처음이면 이름과 비밀번호를 정합니다.
2. 위쪽 탭 Ⅰ~Ⅳ 를 차례로 하면 **자동 저장**됩니다. 집에서 이어서 써도 됩니다.
3. 다 쓰면 **Ⅴ 내 보고서 → [제출하기]**. 공용 컴퓨터라면 꼭 **[나가기]** 를 누릅니다.
